# v4.1 — "The skill sheds the ritual" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rewire the canonical `second-opinion` skill to delegate Stages 1–3 (and Stage-5 artifact materialization) to the v4.0 `amicus council run` engine — keeping the human Stages 0/4/6 Claude-orchestrated — and add headless **debate mode** (Stage 2.5) to the engine so the daily council collapses from ~30 hand-driven tool calls to one engine call plus three human stages.

**Architecture:** Two separable features over the v4.0 engine. **Feature 2 (debate mode, spec §5)** adds a Stage-2.5 rebuttal round inside the engine: a provisional no-ledger tally identifies Contested/Disputed findings → one defense mini-wave (raiser solos) → one re-vote mini-wave (disputing judges) → a final ledgered tally, all as new `run.json` stage checkpoints, with strict trailing-JSON briefing/parse contracts mirroring the v4.0 Stage-2 style and a NEW pure module `src/council/debate.js` for final-tally reassembly. **Feature 1 (skill fast path, spec §4)** rewrites `skills/second-opinion/SKILL.md` to author only the briefing (Stage 0), invoke `amicus council run` once (Stages 1–3+5-artifacts), then run the human decision/lessons stages over the engine's `tally.json`/`run.json`; the old manual mechanics move verbatim-plus-headnote to a new `MANUAL-ORCHESTRATION.md` fallback; a `--claude-review` engine input keeps the Claude-in-council toggle usable in the fast path; a `--render` flag on `council verdict` refreshes the decided `report.html` in place.

**Tech Stack:** Node ≥ 22.12 CommonJS, jest 29, ajv (devDependency, landed by v4.0 Plan A) for schema tests, zod (MCP input schemas — existing). Zero new runtime dependencies, zero new devDependencies.

**Spec:** `docs/superpowers/specs/2026-07-19-v4.1-skill-on-engine-design.md` — covers §4 (skill fast path: §4.2 stage map, §4.3 briefing/date-stamp, §4.4 Claude-in-council, §4.5 CLI/MCP deltas, §4.6 degradation, §4.7 fallback/preflight, §4.8 file moves/postinstall, §4.9 docs-drift), §5 (debate mode: §5.1 state machine, §5.2 CLI/MCP, §5.3 briefings, §5.4 parsers, §5.5 reassembly, §5.6 withdrawals, §5.7 degradation), §6 (testing), §7 (rollout), §8 (compatibility), and all "Resolved questions (Christian, 2026-07-19)" OQ-1…OQ-7 (adopted as written).

**PLAN BOUNDARY (this rev vs siblings):** Debate mode (spec §5) lives **HERE**, not v4.2 — the v4.0 spec deferred it to "v4.1 (or v4.2 at the latest)" and this rev claims it. The `--debate` CLI flag + the `debate?` MCP input + the `run.json` `debate` summary object are a **durable public contract**: v4.7 will make `debate` a pack-able policy option, so their names/shapes must not churn after this lands. This rev does NOT build: policy packs / run profiles (v4.7), local providers (v4.2), watch/streaming/Council Workspace GUI (v4.5/v4.6), `--dry-run` cost preview (backlog), parallel panels, interactive/GUI debate. It adds **zero** new MCP tools (only new inputs on `amicus_council_run` and `amicus_verdict`); tool count stays 15. Feature 1 (skill, Phases 2–4) and Feature 2 (debate engine, Phase 1) are **separable** — Phase 1 ships value with no skill change — but both ride the single **v4.1.0** point release (Phase 6).

## Ambiguities & drift resolved while planning (visible decisions)

1. **Debate wave orchestration lives in a NEW `src/council/run-debate.js`, separate from the pure `src/council/debate.js`.** Spec §5.5 mandates `debate.js` as the *pure* reassembly module (DI-free); but the impure wave orchestration (launch defense solos, launch the re-vote fanout, parse, checkpoint) needs the DI launchers and would push `run.js` (Plan B driver, already dense — Plan B Task 10) past the 300-line gate. So the orchestration goes in `run-debate.js` (`runDebate(ctx, {...})`, launcher-injected like `run-stages.js`), and `debate.js` stays pure. Both are new files < 300 lines. (Global Constraints; spec §5.1/§5.5.)
2. **Debate briefing templates live in a NEW `src/council/briefings-debate.js`, not appended to `briefings-stage2.js`.** `briefings-stage2.js` is a v4.0-new file already carrying judge bundle + chair packet + repairs; adding three debate templates risks the 300-line gate. New file keeps both under gate and keeps the debate contract isolated (the durable-public-contract concern above). (Spec §5.3.)
3. **Parser action verb vs finding decoration verb.** `parseDebateDefense` (spec §5.4) returns present-tense actions `defend|amend|withdraw|no-response`; the finding decoration (spec §5.6) uses past-tense `defended|amended|withdrawn|no-response`. `debate.js` owns the single mapping (`defend→defended`, `amend→amended`, `withdraw→withdrawn`, `no-response→no-response`) so no other module re-derives it.
4. **Date-stamp move touches v4.0-new `briefings-stage2.js`.** Spec §4.3 says `briefings.js` prepends `Today's date is YYYY-MM-DD.` to *every* composed model-facing briefing. In v4.0, `briefings.js`'s `compose()` already injects the date into Stage-1 seat/critic/lens briefings (Plan B Task 3 `dateLine`), but the Stage-2 judge bundle and chair packet (`briefings-stage2.js`) do **not**. So the v4.1 date-stamp addition = add an optional `date` to `buildJudgeBundle`/`buildChairPacket` (and every debate template) that prepends the same `dateLine`. Additive/optional so v4.0 call sites without a date still compose; run.js call sites are updated to pass `o.date` (Task 4). (Spec §4.3; anchor `briefings-stage2.js` is V4.0-NEW.)
5. **ERROR_CODES spelling.** Spec §4.4 spells the pre-flight code `council_claude_review_invalid`; the repo `ERROR_CODES` object convention is SCREAMING_SNAKE (v4.0 Plan B Task 11 established `COUNCIL_QUORUM`/`COST_EXCEEDED`). This plan follows the repo convention: `ERROR_CODES.COUNCIL_CLAUDE_REVIEW_INVALID = 'COUNCIL_CLAUDE_REVIEW_INVALID'`; the human/error-doc `message` carries the spec's lowercase token verbatim for grep-ability.
6. **`--render` appends after the pinned verdict-command tail (spec §4.9 B22).** The B22 docs-drift pin matches `amicus council verdict … --decisions … -o …`; §4.5c requires `--render` to be documented *after* that tail so the pin's regex still matches. In `src/cli.js` usage and SKILL.md, `--render` is added as the last flag line of the `council verdict` block; `isBooleanFlag` gains `render`.
7. **`--no-cost-gate` is already a registered boolean flag** (`src/cli.js:136`) — v4.1 does not re-register it; the CLI handler for `council run` (v4.0-new `src/cli-handlers-council-run.js`) forwards `args['no-cost-gate']` into `runCouncil` options as `noCostGate`, and `run-launch.js` forwards it to every internal launch. `--debate` and `--render` ARE new boolean flags added to `isBooleanFlag`. (Spec §4.5b/§4.5d.)
8. **Claude review is review N+1 sourced from a file — it never spawns a leg.** `--claude-review <path>` is validated pre-flight via the existing `validateFindings`; on success its findings enter `toGlobalFindings` as one more labeled entry and its runStats row is synthesized `{model:'claude', role:'claude', status:'complete', durationMs:null, usage:null, conformance:'clean'}` (nulls per the never-invent rule). No fanout/solo leg is launched for `claude`; no judge leg either. (Spec §4.4a; OQ-2.)
9. **`--chair claude` guard is literal on the reserved seat name.** Any alias resolving to an Anthropic model as chair is out of scope; the enforced guard is the literal string `claude` as `--chair` value (pre-flight error, same envelope as chair-in-bench). (Spec §4.4a.)
10. **Debate decoration is injected into the tally `record` before `writeTallyFiles`, and carried through `buildVerdict`.** `buildVerdict` (Plan A gave it `(record, decisions, opts)`) maps `record.findings[].debate` straight onto the verdict finding when present — additive; council family stays schemaVersion 2. (Spec §5.6; anchor `verdict.js` — the v4.1 change is that `buildVerdict` copies the additive `debate` field through.)
11. **The skill never re-runs `council tally`.** The engine's `tally-final` already appended the ledger row(s); SKILL.md's fast path reads conformance/runStats from `run.json`/`tally.json` and NEVER invokes `council tally` (the double-append guard, pinned by the new `skill-fast-path-docs.test.js`). (Spec §4.2 Stage-6 note; §4.9.)
12. **Fast-path artifacts retire `crossreview-matrix.md` + `verdict.md` (OQ-4).** In the fast path the engine's `report.html`/`report.md --md` section supersedes `crossreview-matrix.md` and `chair-output.md` is the chair-prose artifact (`verdict.md`'s role). The manual path keeps the old names. No copy-to-old-name shim is shipped (OQ-4 final: "I'd rather not ship two names for one artifact").
13. **Stage-0 menu shrinks to four items (OQ-5).** Chair verdict scale is standard-on in the fast path (the engine mandates the `VERDICT:` line headless — v4.0 locked decision 1); the menu notes it "now standard" rather than offering it. The manual path keeps the 5-item menu.
14. **Red-team folds into `--critic` (OQ-3).** Fast-path red-team requests map to `--critic <model>`; fully custom per-seat briefs are a documented manual-path case. The skill drops the standalone red-team-variant launch block from SKILL.md (it moves to MANUAL-ORCHESTRATION.md).
15. **`amicus_verdict render:true` requires an explicit `outDir` to write.** The MCP tool is pure/does-not-write today; §4.5c adds a write side-effect *only when* `render:true` AND `outDir` (absolute) is given — otherwise the tool returns the `--md` rendering in the result but writes nothing (Cowork then writes the file with host tools). This keeps the "pure by default" posture and avoids guessing a write location. (Spec §4.5c; anchor `mcp-server.js:1092`.)
16. **Version is v4.1.0 minor (OQ-7).** Every engine change is additive (flags, MCP inputs, additive JSON fields); the SKILL.md overwrite-on-update is existing postinstall policy; MODEL-NOTES stays machine-local `if-missing`. This rev is its own point release.

**Debate parser results (spec §5.4, Task 1):**

  byId: { [id]: { action: 'defend'|'amend'|'withdraw', argument?: string, claim?: string }
                | { action: 'no-response' } },   // every expectedId present
  ok: boolean,                                    // false ⇒ caller issues 1 repair

Whole-block failure semantics: the caller (run-debate) issues exactly **1** repair re-prompt (solo, quoting `errors`); still-bad ⇒ for defense every expected id becomes `{action:'no-response'}`, for re-vote every id is dropped (originals stand); the leg's `conformance` is recorded `'unstructured'`. Unknown ids not in `expectedIds` are ignored. A *present-but-individually-invalid* id (amend without claim; bad verdict enum) becomes `no-response` for defense / dropped for re-vote — no repair for a well-formed block with one bad entry (`ok:true`, per-id fallback).

```js
const DEBATE_ACTIONS = ['defend', 'amend', 'withdraw'];
const REVOTE_VERDICTS = ['agree', 'dispute', 'neutral'];

/**
 * Parse a debate defense solo (spec §5.4). Every expected id ends up in byId:
 * a present-and-valid entry keeps its action/argument/claim; anything absent or
 * individually invalid becomes {action:'no-response'} (the spec-mandated
 * "original stands" fallback). A block-level failure sets ok:false so the
 * caller issues exactly ONE repair; after that, every id is 'no-response'.
 * @param {string} text raw defense output (prose + trailing ```json block)
 * @param {string[]} expectedIds run-global ids sent to this raiser
 * @returns {{byId: Object, ok: boolean, errors: Array<{code, detail}>}}
 */
function parseDebateDefense(text, expectedIds) {
  const allNoResponse = () => {
    const byId = {};
    for (const id of expectedIds) { byId[id] = { action: 'no-response' }; }
    return byId;
  };
  const body = lastJsonBlock(text || '');
  if (body === null) {
    return { byId: allNoResponse(), ok: false, errors: [{ code: 'NO_FENCED_BLOCK', detail: 'no ```json block found' }] };
  }
  let parsed;
  try { parsed = JSON.parse(body); }
  catch (e) { return { byId: allNoResponse(), ok: false, errors: [{ code: 'NOT_PARSEABLE', detail: e.message }] }; }
  if (!parsed || !Array.isArray(parsed.responses)) {
    return { byId: allNoResponse(), ok: false, errors: [{ code: 'BAD_RESPONSES', detail: 'responses must be an array' }] };
  }
  const expected = new Set(expectedIds);
  const byId = allNoResponse();
  for (const r of parsed.responses) {
    const id = r && r.id;
    if (!expected.has(id)) { continue; }                 // unknown id ignored
    if (r.action === 'defend' && typeof r.argument === 'string' && r.argument.trim()) {
      byId[id] = { action: 'defend', argument: r.argument };
    } else if (r.action === 'amend' && typeof r.claim === 'string' && r.claim.trim()) {
      const entry = { action: 'amend', claim: r.claim };
      if (typeof r.argument === 'string' && r.argument.trim()) { entry.argument = r.argument; }
      byId[id] = entry;
    } else if (r.action === 'withdraw') {
      byId[id] = { action: 'withdraw' };
    } // else leave as no-response
  }
  return { byId, ok: true, errors: [] };
}

/**
 * Parse a re-vote leg (spec §5.4). byId holds ONLY present-and-valid ids; an
 * absent or invalid entry is omitted so the judge's original verdict stands.
 * Block-level failure sets ok:false (caller issues one repair, then originals
 * stand for all bundled ids).
 * @param {string} text raw re-vote output
 * @param {string[]} expectedIds bundled run-global ids
 * @returns {{byId: Object, ok: boolean, errors: Array<{code, detail}>}}
 */
function parseRevote(text, expectedIds) {
  const body = lastJsonBlock(text || '');
  if (body === null) {
    return { byId: {}, ok: false, errors: [{ code: 'NO_FENCED_BLOCK', detail: 'no ```json block found' }] };
  }
  let parsed;
  try { parsed = JSON.parse(body); }
  catch (e) { return { byId: {}, ok: false, errors: [{ code: 'NOT_PARSEABLE', detail: e.message }] }; }
  if (!parsed || !Array.isArray(parsed.revotes)) {
    return { byId: {}, ok: false, errors: [{ code: 'BAD_REVOTES', detail: 'revotes must be an array' }] };
  }
  const expected = new Set(expectedIds);
  const byId = {};
  for (const r of parsed.revotes) {
    const id = r && r.id;
    if (!expected.has(id) || !REVOTE_VERDICTS.includes(r.verdict)) { continue; }
    const entry = { verdict: r.verdict };
    if (typeof r.reason === 'string' && r.reason.trim()) { entry.reason = r.reason; }
    byId[id] = entry;
  }
  return { byId, ok: true, errors: [] };
}

/**
 * @module council/briefings-debate
 * Pure Stage-2.5 (debate) template builders for the headless council engine
 * (spec §5.3). Adapted from skills/second-opinion/SEAT-BRIEFS.md § Rebuttal-round
 * templates, hardened from the line-based contract to the v4.0 Stage-2
 * trailing-JSON style (prose first, one fenced ```json block last, nothing
 * after it). Every brief opens with the no-tools preamble and the date stamp
 * (spec §4.3). No IO, no model calls.
 */

const DEBATE_NO_TOOLS_PREAMBLE =
  'Do NOT use any tools or read any files; everything is in this message; ' +
  'begin immediately with the JSON block.';

/** Defense trailing-JSON contract (spec §5.3a). */
const DEFENSE_CONTRACT = [
  'End your response with a fenced ```json block, with no text after it:',
  '',
  '```json',
  '{',
  '  "responses": [',
  '    { "id": "A1", "action": "defend", "argument": "<strongest evidence-based defense, one paragraph max>" },',
  '    { "id": "A3", "action": "amend", "claim": "<full corrected replacement claim>", "argument": "<why, one sentence>" },',
  '    { "id": "B2", "action": "withdraw" }',
  '  ]',
  '}',
  '```',
  '',
  'Every listed finding id must appear exactly once. `defend` requires `argument`; ' +
  '`amend` requires `claim`; `withdraw` requires neither.',
].join('\n');

/** Re-vote trailing-JSON contract (spec §5.3b). */
const REVOTE_CONTRACT = [
  'End your response with a fenced ```json block, with no text after it:',
  '',
  '```json',
  '{',
  '  "revotes": [',
  '    { "id": "A1", "verdict": "agree", "reason": "<one line>" },',
  '    { "id": "A3", "verdict": "dispute", "reason": "<one line>" }',
  '  ]',
  '}',
  '```',
  '',
  '`verdict` is one of agree | dispute | neutral. Every listed finding id must ' +
  'appear exactly once.',
].join('\n');

function findingBlockDefense(f) {
  const reasons = (f.disputeReasons || []).map(r => `    - ${r}`).join('\n');
  const loc = f.location ? ` @ ${f.location}` : '';
  return `- ${f.id} [${f.severity}]${loc}: ${f.claim}\n  Peers disputed it for:\n${reasons}`;
}

function findingBlockRevote(f) {
  const mark = f.amended ? ' **AMENDED**' : '';
  return `- ${f.id} [${f.severity}]${mark}: ${f.claim}\n  Raiser's response: ${f.argument}`;
}

/** One defense solo per raiser (spec §5.3a). */
function buildDefenseBrief({ findings, date }) {
  const parts = [DEBATE_NO_TOOLS_PREAMBLE];
  if (date) { parts.push(dateLine(date)); }
  parts.push(
    'You reviewed an artifact and raised the findings below. Peer reviewers ' +
    '(anonymous) disputed them for the stated reasons. For EACH finding decide: ' +
    'DEFEND it with evidence, AMEND it with corrected replacement text, or WITHDRAW ' +
    'it. Withdraw anything you cannot defend with evidence — an unsupported repeat ' +
    'of the original claim is weaker than a withdrawal.',
    findings.map(findingBlockDefense).join('\n\n'),
    DEFENSE_CONTRACT,
  );
  return parts.join('\n\n');
}

/** One shared re-vote bundle, fanned out to disputing judges (spec §5.3b). */
function buildRevoteBundle({ findings, date }) {
  const parts = [DEBATE_NO_TOOLS_PREAMBLE];
  if (date) { parts.push(dateLine(date)); }
  parts.push(
    'You previously adjudicated findings on this artifact and disputed at least ' +
    'one of those below. The (anonymous) raiser has now responded. Re-adjudicate ' +
    'ONLY the findings listed, in light of each response. Changing your verdict ' +
    'when the defense is convincing is good judging, not weakness; so is holding ' +
    'your dispute when it isn\'t.',
    findings.map(findingBlockRevote).join('\n\n'),
    REVOTE_CONTRACT,
  );
  return parts.join('\n\n');
}

function repair(kind, contract, errors) {
  const lines = (errors || []).map(e => `- ${e.code}: ${e.detail}`).join('\n');
  return [
    'Do NOT use any tools or read any files; everything is in this message; begin ' +
    'immediately with the JSON block.',
    `Your previous ${kind} response's trailing JSON failed validation with these errors:`,
    lines,
    'Re-emit ONLY the corrected JSON block as a single fenced ```json block:',
    contract,
  ].join('\n\n');
}

function buildDefenseRepairPrompt({ errors }) { return repair('defense', DEFENSE_CONTRACT, errors); }
function buildRevoteRepairPrompt({ errors }) { return repair('re-vote', REVOTE_CONTRACT, errors); }

/**
 * Chair-packet "Debate round outcomes" section (spec §5.3c). De-anonymized —
 * built by run.js from debate.json + both tally records.
 * @param {{outcomes: Array<{id, originalClaim, action, amendedClaim, revoteChanges: Array<{judge, before, after}>}>}} args
 */
function buildDebateAddendum({ outcomes }) {
  const blocks = outcomes.map(o => {
    const head = `- ${o.id}: "${o.originalClaim}" → ${o.action}`;
    const amended = o.action === 'amended' && o.amendedClaim ? `\n  Amended claim: "${o.amendedClaim}"` : '';
    const changes = o.revoteChanges.length
      ? '\n  Re-vote changes: ' + o.revoteChanges.map(c => `${c.judge}: ${c.before} → ${c.after}`).join('; ')
      : '\n  Re-vote changes: none';
    return head + amended + changes;
  }).join('\n');
  return ['--- Debate round outcomes ---', blocks].join('\n\n');
}

module.exports = {
  DEBATE_NO_TOOLS_PREAMBLE, DEFENSE_CONTRACT, REVOTE_CONTRACT,
  buildDefenseBrief, buildRevoteBundle,
  buildDefenseRepairPrompt, buildRevoteRepairPrompt, buildDebateAddendum,
};

// src/council/debate.js
'use strict';

/**
 * @module council/debate
 * PURE final-tally reassembly for headless debate mode (spec §5.5). DI-free —
 * takes the provisional tally input + parsed defense/re-vote maps and returns a
 * new tally input plus the debate.json findings rows. run.js then re-runs
 * tally() on the returned input and decorates the record. Keeps run.js under the
 * line gate.
 */

const PAST_TENSE = { defend: 'defended', amend: 'amended', withdraw: 'withdrawn', 'no-response': 'no-response' };

/**
 * Reassemble the tally input after the debate round.
 * @param {{tallyInput: object, provisionalRecord: object|null,
 *   defenseByRaiser: Object<string, Object<string, object>>,
 *   revoteByJudge: Object<string, Object<string, {verdict, reason?}>>}} args
 * @returns {{input: object, debateFindings: Array}}
 */
function applyDebate({ tallyInput, defenseByRaiser, revoteByJudge }) {
  // Deep-ish clone the mutable arrays we touch (findings + adjudications).
  const findings = tallyInput.findings.map(f => ({ ...f }));
  const adjudications = tallyInput.adjudications.map(a => ({ ...a }));

  // Flatten the per-raiser defense map to a per-id lookup + debate.json rows.
  const byId = {};
  const debateFindings = [];
  for (const [raiser, perId] of Object.entries(defenseByRaiser || {})) {
    for (const [id, resp] of Object.entries(perId)) {
      byId[id] = resp;
      const src = findings.find(f => f.id === id) || {};
      const row = { id, raiser, action: resp.action, previousTier: src.previousTier || null };
      if (resp.argument) { row.argument = resp.argument; }
      if (resp.claim) { row.claim = resp.claim; }
      debateFindings.push(row);
    }
  }

  // Amend: swap claim text in place. Withdraw/defend/no-response: findings[] unchanged.
  for (const f of findings) {
    const resp = byId[f.id];
    if (resp && resp.action === 'amend' && typeof resp.claim === 'string') { f.claim = resp.claim; }
    delete f.previousTier; // provisional-only scratch field, never written to tally input
  }

  // Re-vote replacement: replace the wave judge's entry on each bundled id.
  for (const [judge, perId] of Object.entries(revoteByJudge || {})) {
    for (const [id, rv] of Object.entries(perId)) {
      const entry = adjudications.find(a => a.findingId === id && a.judge === judge);
      if (entry) { entry.verdict = rv.verdict; }
      else { adjudications.push({ findingId: id, judge, verdict: rv.verdict }); }
    }
  }

  return { input: { ...tallyInput, findings, adjudications }, debateFindings };
}

/**
 * Inject the additive past-tense debate decoration onto the tally record's
 * findings (spec §5.6). Mutates + returns the record.
 * @param {object} record tally() output
 * @param {Array<{id, action, previousTier}>} debateFindings
 * @returns {object} record
 */
function decorateRecord(record, debateFindings) {
  const byId = new Map((debateFindings || []).map(d => [d.id, d]));
  for (const f of record.findings) {
    const d = byId.get(f.id);
    if (d) { f.debate = { action: PAST_TENSE[d.action] || 'no-response', previousTier: d.previousTier }; }
  }
  return record;
}

/**
 * runStats rows for the debate legs (spec §5.5). role is 'rebuttal' | 'revote';
 * these legs never enter meta.models, so the ledger stays one row per (run×model).
 * @param {{defenseLegs: Array, revoteLegs: Array}} args leg metadata
 * @returns {Array<object>}
 */
function debateRunStatsRows({ defenseLegs, revoteLegs }) {
  const mk = (role) => (l) => ({
    model: l.model, role, wasChair: false, conformance: l.conformance || 'clean',
    status: l.status || 'unknown',
    durationMs: typeof l.durationMs === 'number' ? l.durationMs : null,
    usage: l.usage || null,
  });
  return [...(defenseLegs || []).map(mk('rebuttal')), ...(revoteLegs || []).map(mk('revote'))];
}

module.exports = { applyDebate, decorateRecord, debateRunStatsRows, PAST_TENSE };

// src/council/run-debate.js
'use strict';

/**
 * @module council/run-debate
 * Impure Stage-2.5 orchestration for headless debate mode (spec §5.1). Launches
 * the defense mini-wave (one solo per raiser) and the re-vote mini-wave (one
 * fanout to disputing judges), parses each with one bounded repair, then hands
 * off to the pure reassembly in ./debate.js. Kept out of run.js for the 300-line
 * gate. Launchers are injected via ctx (repo DI pattern).
 */

const fs = require('fs');
const path = require('path');
const dbrief = require('./briefings-debate');
const { parseDebateDefense, parseRevote } = require('./parse-stage2');
const { applyDebate, debateRunStatsRows } = require('./debate');
const { materializeDebate } = require('./run-launch');
const { tally } = require('./tally');
const { isAbortExit } = require('./run-stages');

/** True when there is nothing to challenge (spec §5.1). */
function nothingToDebate(provisionalRecord) {
  if (!provisionalRecord || provisionalRecord.judged === false) { return true; }
  const n = provisionalRecord.findings.filter(f => f.tier === 'Contested' || f.tier === 'Disputed').length;
  return n === 0;
}

/** Judges whose provisional adjudications dispute at least one bundled id. */
function disputingJudges(provisionalRecord, bundledIds) {
  const ids = new Set(bundledIds);
  const judges = new Set();
  for (const f of provisionalRecord.findings) {
    if (!ids.has(f.id)) { continue; }
    for (const adj of f.adjudications || []) {
      if (adj.verdict === 'dispute') { judges.add(adj.judge); }
    }
  }
  return [...judges];
}

/** Group Contested+Disputed findings by raiser (defense targets). */
function debateTargets(provisionalRecord, tallyInput) {
  const claimById = new Map(tallyInput.findings.map(f => [f.id, f]));
  const byRaiser = {};
  const previousTier = {};
  for (const f of provisionalRecord.findings) {
    if (f.tier !== 'Contested' && f.tier !== 'Disputed') { continue; }
    previousTier[f.id] = f.tier;
    const src = claimById.get(f.id) || {};
    const reasons = (f.adjudications || []).filter(a => a.verdict === 'dispute').map(() => 'a peer disputed this finding');
    (byRaiser[f.raiser] = byRaiser[f.raiser] || []).push({
      id: f.id, claim: src.claim, severity: f.severity, disputeReasons: reasons,
    });
  }
  return { byRaiser, previousTier };
}

async function runDefenseSolo(ctx, raiser, findings, idx) {
  const brief = dbrief.buildDefenseBrief({ findings, date: ctx.o.date });
  const waveId = `${ctx.o.runId}-d${idx + 1}`;
  const expectedIds = findings.map(f => f.id);
  let res = await ctx.launchers.launchSolo({
    model: raiser, prompt: brief, project: ctx.scratchDir, waveId,
    timeout: ctx.o.timeout, gateway: ctx.o.gateway, noCostGate: ctx.o.noCostGate,
  });
  ctx.addWave(res.wave);
  if (isAbortExit(res.exitCode)) { return { raiser, aborted: res.exitCode }; }
  let leg = res.leg && res.leg.status === 'complete' ? res.leg : null;
  let parsed = leg ? parseDebateDefense(leg.summary, expectedIds) : { ok: false, byId: {}, errors: [{ code: 'DEAD_LEG', detail: 'no summary' }] };
  let conformance = leg ? 'clean' : 'unstructured';
  if (leg && !parsed.ok) {
    const repair = dbrief.buildDefenseRepairPrompt({ errors: parsed.errors });
    const res2 = await ctx.launchers.launchSolo({ model: raiser, prompt: repair, project: ctx.scratchDir,
      waveId: `${waveId}r`, timeout: ctx.o.timeout, gateway: ctx.o.gateway, noCostGate: ctx.o.noCostGate });
    ctx.addWave(res2.wave);
    if (isAbortExit(res2.exitCode)) { return { raiser, aborted: res2.exitCode }; }
    const leg2 = res2.leg && res2.leg.status === 'complete' ? res2.leg : null;
    parsed = leg2 ? parseDebateDefense(leg2.summary, expectedIds) : parsed;
    conformance = parsed.ok ? 'repaired' : 'unstructured';
    if (leg2) { leg = leg2; }
  } else if (leg) {
    conformance = 'clean';
  }
  // Block-level failure after repair → every expected id no-response (parser already did this).
  // A dead leg (no complete summary) OR an 'unstructured' conformance after the one repair
  // is a debate degradation (spec §5.7) — surfaced via the returned leg for the exit-2 check.
  return { raiser, byId: parsed.byId, leg: leg ? { model: raiser, status: leg.status, durationMs: leg.durationMs, usage: leg.usage, conformance, summary: leg.summary } : { model: raiser, status: 'error', durationMs: null, usage: null, conformance: 'unstructured', summary: '' } };
}

async function runRevoteWave(ctx, judges, bundleFindings) {
  const bundle = dbrief.buildRevoteBundle({ findings: bundleFindings, date: ctx.o.date });
  const waveId = `${ctx.o.runId}-rv`;
  const expectedIds = bundleFindings.map(f => f.id);
  const res = await ctx.launchers.launchWave({
    models: judges, prompt: bundle, project: ctx.scratchDir, waveId,
    timeout: ctx.o.timeout, gateway: ctx.o.gateway, noCostGate: ctx.o.noCostGate,
  });
  ctx.addWave(res.wave);
  if (isAbortExit(res.exitCode)) { return { aborted: res.exitCode }; }
  const byJudge = {};
  const legs = [];
  for (const leg of (res.wave.legs || [])) {
    const alive = leg.status === 'complete' && leg.summary;
    let parsed = alive ? parseRevote(leg.summary, expectedIds) : { ok: false, byId: {}, errors: [{ code: 'DEAD_LEG', detail: 'no summary' }] };
    let conformance = alive ? 'clean' : 'unstructured';
    if (alive && !parsed.ok) {
      // One repair, solo, to that judge.
      const repair = dbrief.buildRevoteRepairPrompt({ errors: parsed.errors });
      const r2 = await ctx.launchers.launchSolo({ model: leg.model, prompt: repair, project: ctx.scratchDir,
        waveId: `${waveId}-${leg.model}r`, timeout: ctx.o.timeout, gateway: ctx.o.gateway, noCostGate: ctx.o.noCostGate });
      ctx.addWave(r2.wave);
      if (isAbortExit(r2.exitCode)) { return { aborted: r2.exitCode }; }
      const leg2 = r2.leg && r2.leg.status === 'complete' ? r2.leg : null;
      parsed = leg2 ? parseRevote(leg2.summary, expectedIds) : parsed;
      conformance = parsed.ok ? 'repaired' : 'unstructured';
    }
    byJudge[leg.model] = parsed.byId;
    legs.push({ model: leg.model, status: leg.status, durationMs: leg.durationMs, usage: leg.usage, conformance, summary: leg.summary || '' });
  }
  return { byJudge, legs };
}

/**
 * Full Stage-2.5 sequence (spec §5.1). Returns everything run.js needs.
 * Cost gate: the caller (run.js) already checks overBudget before invoking; this
 * function checks again before the re-vote wave (spec §5.7).
 */
async function runDebate(ctx, { provisionalRecord, tallyInput, judgeResults }) {
  const { byRaiser, previousTier } = debateTargets(provisionalRecord, tallyInput);
  const contested = provisionalRecord.findings.filter(f => f.tier === 'Contested').length;
  const disputed = provisionalRecord.findings.filter(f => f.tier === 'Disputed').length;

  // ---- Defense mini-wave (one solo per raiser) ----
  const raisers = Object.keys(byRaiser);
  const defenseResults = [];
  for (let i = 0; i < raisers.length; i++) {
    const dr = await runDefenseSolo(ctx, raisers[i], byRaiser[raisers[i]], i);
    // A signal during the defense wave aborts the whole finalization (spec §5.7):
    // return the abort code so run.js finalizes 'aborted' with NO tally-final / NO ledger.
    if (dr.aborted) { return { aborted: dr.aborted }; }
    defenseResults.push(dr);
  }
  materializeDebate(ctx.o.runDir, defenseResults.map(d => ({ model: d.raiser, summary: d.leg.summary })), 'rebuttal');

  // Attach previousTier to each defended finding for debate.json / decoration.
  const defenseByRaiser = {};
  for (const dr of defenseResults) {
    defenseByRaiser[dr.raiser] = {};
    for (const [id, resp] of Object.entries(dr.byId)) { defenseByRaiser[dr.raiser][id] = resp; }
  }
  // Stamp previousTier onto the tally input findings so applyDebate can read it.
  const stampedInput = { ...tallyInput, findings: tallyInput.findings.map(f => ({ ...f, previousTier: previousTier[f.id] })) };

  // Which findings were defended or amended (the re-vote bundle) — withdrawn/no-response never re-voted.
  const defendedOrAmended = [];
  for (const dr of defenseResults) {
    for (const [id, resp] of Object.entries(dr.byId)) {
      if (resp.action === 'defend' || resp.action === 'amend') {
        const src = tallyInput.findings.find(f => f.id === id) || {};
        defendedOrAmended.push({ id, severity: src.severity, amended: resp.action === 'amend',
          claim: resp.action === 'amend' ? resp.claim : src.claim, argument: resp.argument || 'defended without extra argument' });
      }
    }
  }

  // ---- Re-vote mini-wave (disputing judges only) ----
  let revoteByJudge = {};
  let revoteLegs = [];
  const bundledIds = defendedOrAmended.map(f => f.id);
  const judges = disputingJudges(provisionalRecord, bundledIds);
  // A re-vote is warranted only when something was defended/amended AND ≥1 judge disputed it.
  // Skipping THAT case because the whole-run budget is spent is the 'skipped-cost-ceiling'
  // degradation branch (spec §5.7); skipping because there is simply nothing to re-vote is NOT.
  const wouldRevote = defendedOrAmended.length > 0 && judges.length > 0;
  const costCeiling = ctx.overBudget() && wouldRevote;
  const skipRevote = ctx.overBudget() || !wouldRevote;
  if (!skipRevote) {
    const rv = await runRevoteWave(ctx, judges, defendedOrAmended);
    if (rv.aborted) { return { aborted: rv.aborted }; }
    revoteByJudge = rv.byJudge;
    revoteLegs = rv.legs;
  }

  // ---- Pure reassembly ----
  const { input: debatedInput, debateFindings } = applyDebate({ tallyInput: stampedInput, provisionalRecord, defenseByRaiser, revoteByJudge });
  debatedInput.runStats = [...(debatedInput.runStats || []),
    ...debateRunStatsRows({ defenseLegs: defenseResults.map(d => d.leg), revoteLegs })];

  // verdictChanges: findings whose tier moved from provisional to debated.
  const provTierById = new Map(provisionalRecord.findings.map(f => [f.id, f.tier]));
  const debatedRec = tally(debatedInput);
  let verdictChanges = 0;
  for (const f of debatedRec.findings) { if (provTierById.get(f.id) !== f.tier) { verdictChanges += 1; } }

  // ---- Artifacts + summary ----
  const revotesJson = [];
  for (const [judge, perId] of Object.entries(revoteByJudge)) {
    for (const [id, rv] of Object.entries(perId)) { revotesJson.push({ judge, id, verdict: rv.verdict, reason: rv.reason || null, applied: true }); }
  }
  const debateJson = { findings: debateFindings, revotes: revotesJson };
  fs.writeFileSync(path.join(ctx.o.runDir, 'debate.json'), JSON.stringify(debateJson, null, 2), { mode: 0o600 });

  const counts = { defended: 0, amended: 0, withdrawn: 0, noResponse: 0 };
  for (const df of debateFindings) {
    if (df.action === 'defend') { counts.defended += 1; }
    else if (df.action === 'amend') { counts.amended += 1; }
    else if (df.action === 'withdraw') { counts.withdrawn += 1; }
    else { counts.noResponse += 1; }
  }
  const debateSummary = {
    enabled: true, outcome: costCeiling ? 'skipped-cost-ceiling' : 'ran',
    contested, disputed, ...counts,
    revoteJudges: revoteLegs.length, revoteApplied: revotesJson.length, verdictChanges,
  };

  // ---- Degradation (spec §5.7) → run.js maps this to exit code 2 ----
  // A dead/unstructured-after-repair defense solo, a partial or fully-dead re-vote wave,
  // or a cost-ceiling skip of a warranted re-vote each degrade the run. (Abort is handled
  // above by short-circuiting; nothing-to-debate and a clean run are NOT degradations.)
  const defenseDegraded = defenseResults.some(d => d.leg.status !== 'complete' || d.leg.conformance === 'unstructured');
  const revoteDegraded = revoteLegs.some(l => l.status !== 'complete' || l.conformance === 'unstructured');
  const degraded = defenseDegraded || revoteDegraded || costCeiling;

  // Chair-addendum outcomes (spec §5.3c).
  const addendumOutcomes = debateFindings.map(df => ({
    id: df.id, originalClaim: (tallyInput.findings.find(f => f.id === df.id) || {}).claim,
    action: require('./debate').PAST_TENSE[df.action], amendedClaim: df.action === 'amend' ? df.claim : null,
    revoteChanges: revotesJson.filter(r => r.id === df.id).map(r => ({
      judge: r.judge, before: 'dispute', after: r.verdict,
    })),
  }));

  return { debatedInput, debateFindings, debateSummary, addendumOutcomes,
    defenseLegs: defenseResults.map(d => d.leg), revoteLegs, verdictChanges,
    degraded, aborted: null };
}

module.exports = { runDebate, nothingToDebate, disputingJudges, debateTargets };

  `Defending.\n\n\`\`\`json\n${JSON.stringify({ responses })}\n\`\`\`\n`;

const revoteOut = (revotes) =>

/**
 * Build launchers from a flat `{[waveId]: (opts) => {wave, exitCode}}` map (the
 * same shape scriptedLaunchers dispatches on), firing an optional onLaunch(opts)
 * hook exactly ONCE per launch (wave or solo). Throws on an unscripted waveId so
 * a test can prove a launch did NOT happen (e.g. no leg for 'claude'). Records
 * every launch's opts in `.calls`; solos expose `leg = wave.legs[0] || null`.
 */
function launchersFromScript(script, onLaunch) {
  const calls = [];
  async function dispatch(opts) {
    calls.push(opts);
    if (onLaunch) { onLaunch(opts); }
    const fn = script[opts.waveId];
    if (!fn) { throw new Error(`no script for waveId ${opts.waveId}`); }
    return fn(opts);
  }
  return {
    calls,
    launchWave: (opts) => dispatch(opts),
    launchSolo: async (opts) => {
      const r = await dispatch({ ...opts, models: [opts.model] });
      return { ...r, leg: (r.wave && r.wave.legs && r.wave.legs[0]) || null };
    },
  };
}
