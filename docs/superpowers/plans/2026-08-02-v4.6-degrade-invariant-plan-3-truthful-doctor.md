# v4.6 Degrade Announcement Invariant — Plan 3: Truthful Doctor

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `doctor` speaks the invariant's language — failed checks become degrade records on its
artifact, every `--fix` repair announces itself as a heal in the one voice, and no hint asserts a
cause that was never verified.

**Architecture:** Doctor's existing check rows (`{id,name,status,message,hint}` — a schema'd
`--json` contract) are NOT rewritten. A pure collector (`src/utils/doctor-degrade.js`) maps rows
to shared-vocabulary records: `status:'error'` rows → `kind:'degrade'`, and rows carrying a new
structured `fixed` flag → `kind:'heal'`. The five `--fix` sites set that flag where they already
hold the outcome (no prose parsing — the Plan 2 rule). `doctor --json` gains additive
`degrades[]`; human output gains `Recovered:` lines (heals only — ✗ rows already carry the
failures); the exit code is UNCHANGED (error-derived, which is definitionally "any
`kind:'degrade'` present"). The canned cause-guessing hints become unverified-cause statements.

**Tech Stack:** Node.js (CommonJS), jest 29.7.0, eslint, `scripts/check-file-sizes.js` (300-line gate).

**Spec:** `docs/superpowers/specs/2026-08-01-degrade-announcement-invariant-design.md` (§4 doctor
collector, §5 doctor channels, §6 doctor flow, §7 check-throw handling, D7, success criteria 4+6).

**Measured reality this plan is written against (`feat/v4.6-plan-2-verdict-surface` @ `e2e99b2`,
2026-08-02) — the spec's doctor sketch predates v4.5.x; re-measured per the plan-rot ruling:**

```js
// src/utils/doctor-degrade.js
'use strict';

/**
 * @module utils/doctor-degrade
 * The doctor-side collector (spec §4): maps doctor's check rows onto the shared
 * degrade/heal vocabulary. Pure — reads row STATUS and the structured `fixed`
 * flag only, never message prose (the Plan 2 rule: prose is the human surface).
 *
 * Mapping (spec §6, with the recorded interpretation):
 *   status 'error'      → kind 'degrade', channel 'doctor-check-failed'
 *   row.fixed === true  → kind 'heal',    channel 'doctor-fix'
 *   'ok'/'warn' rows    → no record — doctor's exit code ignores warns, and the
 *                         §6 equivalence (exit derives from any degrade) must
 *                         hold without changing exit behavior.
 * A row can produce both (a partial self-heal that still fails).
 * Never throws: a malformed row degrades honestly, mirroring the council sink.
 */
const { makeDegrade } = require('./degrade');

function collectDoctorDegrades(checks) {
  const records = [];
  for (const c of Array.isArray(checks) ? checks : []) {
    if (!c) { continue; }
    const name = c.name || c.id || 'unnamed';
    if (c.status === 'error') {
      records.push(makeDegrade({
        channel: 'doctor-check-failed',
        what: `the '${name}' check failed`,
        why: (typeof c.message === 'string' && c.message.trim()) ? c.message : 'the check produced no message',
        effect: 'amicus may not work correctly until this is fixed; doctor exits 1',
        ...(typeof c.hint === 'string' && c.hint.trim() ? { remedy: c.hint } : {}),
        data: { checkId: c.id || null },
      }));
    }
    if (c.fixed === true) {
      records.push(makeDegrade({
        kind: 'heal',
        channel: 'doctor-fix',
        what: `the '${name}' check was repaired in place`,
        why: (typeof c.fixDetail === 'string' && c.fixDetail.trim())
          ? `doctor --fix ${c.fixDetail}`
          : "doctor --fix applied the check's self-heal",
        effect: 'no further action needed; the repair already ran',
        data: { checkId: c.id || null },
      }));
    }
  }
  return records;
}

module.exports = { collectDoctorDegrades };
```
