**Goal:** Add local / OpenAI-compatible endpoints (Ollama, LM Studio, vLLM, any self-hosted OpenAI-compatible server) as a first-class **third route class** — `gateway: 'local'` — so sidecars, fanouts, and council seats run at zero marginal cost, privately, offline, with a `config.providers` schema, a live reachability probe, a real **$0 pricing tier**, `amicus provider`/`amicus key` add flows, a doctor check, and the ride-along polish `amicus init` (C2), a wizard-end doctor summary (C8), and real docs for `spend`/`doctor`/`key`/`provider`/`init` (C10).

**Architecture:** A new merge layer (`src/utils/local-providers.js`) reads validated provider entries from `config.providers` beside the untouched static 5-vendor `provider-registry.js`; the pure `#61` router (`gateway-router.js`) gains one `local` branch fed two injected inputs (the normalized provider map + a bounded live probe) assembled by `route-launch.js`; `buildProviderModels` emits the `@ai-sdk/openai-compatible` block the bundled engine already executes via `options.baseURL` + `{env:VAR}` interpolation (amicus writes config only, no HTTP client, no key material in config.json). Local rows flow through the existing catalog, pricing, budget, spend, and picker paths as a **priced-at-$0 tier** (never "unpriced-null").

**Tech Stack:** Node ≥ 22.12 CommonJS, jest, no new runtime deps. Local execution rides entirely on the bundled OpenCode engine's built-in `@ai-sdk/openai-compatible` adapter (verified in the binary: 54× `openai-compatible`, 278× `baseURL`, built-in `lmstudio` provider, `{env:VAR}` interpolation). The one offline-testable provider class ⇒ a hermetic stub OpenAI-compatible server (`node:http`) is the flagship e2e.

**Spec:** `docs/superpowers/specs/2026-07-19-v4.2-local-providers-design.md` (finalized 2026-07-19; every Resolved-question LOCKED). ## Ambiguities & drift resolved while planning (visible decisions)

1. **Key-presence must reach the pure router without I/O.** Spec §4.2 step 2 (`apiKeyEnv declared but no value present → no_local_key`) requires a `.env`/`process.env` read, but `gateway-router.js`'s `resolveRoute` is pure (no I/O — verified `src/utils/gateway-router.js:1-13`). **Decision:** `route-launch.js` resolves each entry's bearer presence during assembly and stamps a computed `keyPresent: boolean` onto the normalized entry it injects via `req.localProviders`; the router branch reads `entry.apiKeyEnv && !entry.keyPresent`. Keeps the router pure (mirrors how `buildLaunchKeys()` already pre-resolves key presence for direct vendors, `route-launch.js:21-29`).

2. **Probe helper is its own module, shared by router-assembly and catalog.** Spec §3 (http-scheme fix row) + §4.2 + §4.4 all reference "the new scheme-aware fetch" used by BOTH the route-time probe and `fetchAllModels`. `model-fetcher.js:8` hardcodes `require('https')`. **Decision:** a new leaf module `src/utils/local-probe.js` owns the scheme-aware `node:http`/`node:https` GET, `probeLocalProvider(entry, {timeoutMs})` (route-time, `/v1/models` primary → ollama-flavor `/api/tags` fallback) and `listLocalModels(entry, {timeoutMs})` (catalog rows). `model-fetcher.js`'s existing `https`-only helper is left untouched for the 5 direct vendors (they are all `https`); local fetches never route through it.

3. **`local-probe.js` returns `<id>/<model>` ids, not bare model names.** Spec §4.2 says `localLive.models: ['<id>/<model>', ...]` and §4.4 catalog rows are `{id:'<pid>/<model>'}`. **Decision:** the probe normalizes each raw server model name (`/v1/models` `data[].id`, or `/api/tags` `models[].name`) to `<providerId>/<rawName>` so the router's model-membership check and the catalog id are the same shape as `resolveRoute`'s `executableId`. Colons inside the raw name (`qwen3:14b`) are preserved verbatim (`parseModelString` splits on the first `/` only — verified `opencode-client.js:73`).

3a. **Probe status vocabulary.** `probeLocalProvider` returns `{status:'ok'|'unreachable', models:[]}`. `'skipped'` is set by `route-launch.js` (NOT by the probe) when `validateModel === false` — the probe is never called in that case; the router treats `'skipped'` as `unknown` (resolve with an "unverified; attempting anyway" notice), exactly the tri-state contract `catalogGate` already honors (`gateway-router.js:24-31`).

4. **Router branch placement is between explicit-OR (step 3) and gateway-only-vendor (step 4).** Spec §4.2: "placed after descriptor normalization and the explicit-OR handling, before the gateway-only-vendor check". In `gateway-router.js:79-100` that is immediately after the `d.isExplicitOpenRouter` block and before `if (!isDirectProvider(vendor))`. This ordering is what makes a local id shadow a gateway-only OpenRouter vendor namespace for bare descriptors (resolved Q6). An explicit `openrouter/<id>/…` literal still hits step 2/3 first (grammar outranks shadowing) → `no_openrouter_route`.

5. **Shadowing detection at `provider add` is catalog-based, not a maintained blocklist.** Resolved Q6 rejects a stale OR-vendor blocklist. **Decision:** `provider add` warns about shadowing only when the cached catalog actually contains any row id starting with `openrouter/<id>/` — concrete, self-updating, never stale. Reserved built-ins (`openrouter`/`google`/`openai`/`anthropic`/`deepseek`) are a hard reject (spec §4.1 id rules), separate from the shadow warning.

6. **`gateway: 'local'` is NOT added to the `--gateway` enum.** Spec §4.2: "The `--gateway` enum stays `auto|direct|openrouter` — no new flag value." Resolved Q2: `--gateway direct` on a local vendor **resolves** (a local endpoint is direct-in-spirit); `gatewayMode === 'openrouter'` on a local vendor **errors** (`no_openrouter_route`). `'local'` is only ever a `RouteResult.gateway` value.

7. **New error reasons are added to `REASON_TEXT`/`FIX_HINTS` but NOT to `ROUTE_ERROR_REASONS`.** `route-error.js:41-49` `ROUTE_ERROR_REASONS` is frozen and pinned by `route-error.test.js` to exactly 7 base values, and its own doc-comment says "must not be extended" (`route-error.js:32-39`). **Decision:** `no_openrouter_route`, `no_local_key`, `local_endpoint_unreachable` get `REASON_TEXT` + `FIX_HINTS` entries (like the existing `direct_unavailable`/`openrouter_unavailable` availability reasons, which are also outside the frozen array); `model_not_found` is reused for the model-absent case with a flavor-specific hint appended at the router. This keeps `route-error.test.js:14-24` green untouched.

8. **The $0 tier is a real priced tier via an explicit-zero branch, not tolerated-null.** `pricing.js:59` requires `est > 0` for `source:'estimated'`, so a genuine $0 leg falls through to `unknown`/null today. Spec §4.5 wants local legs counted as **priced $0**. **Decision:** `resolveLegCost` gains a branch — when `pricing` is present and the token-weighted estimate is exactly `0`, return `{amount: 0, currency:'USD', source:'estimated'}`. `lookupPricing` gains a local fallback (no catalog row + vendor is local → the provider's configured `pricing`, default `{prompt:0, completion:0}`). `formatCost(0)` already renders `~$0.0000` for `source:'estimated'` (verified `pricing.js:100-106`) — no change there. No ledger/spend schema bump.

9. **`local: true` catalog rows must be excluded from `networkRows` in `refreshCatalog`.** `model-catalog.js:99` only excludes `anthropic/` floor rows from the "did the network refresh succeed" filter. A localhost-only refresh (offline except loopback) would otherwise count as success and clobber a good OpenRouter cache. **Decision:** widen the filter to also drop rows where `m.local === true`. One-line change + regression test (spec §4.4 "regression trap found during design").

10. **Council no-drop keys off the local-provider map, not a row flag.** `resolveCouncilMembers` (`config.js:376-402`) drops members absent from a non-empty catalog. **Decision:** a member whose resolved vendor id is a key in `getLocalProviders()` is never dropped on catalog absence (spec §4.4) — the leg still fails pre-flight with the actionable unreachable error if the server is truly down.

11. **New `amicus provider` command block registered in `USAGE_COMMAND_BLOCKS`.** `cli.js:384` `USAGE_COMMAND_BLOCKS` + `getCommandNames()` (`cli.js:598-600`) drive typo-suggestions and `--help`. `provider` and `init` get blocks there and `case` arms in `bin/amicus.js`'s switch (`bin/amicus.js:82-137`).

12. **`amicus provider` handlers live in a new `src/cli-handlers-provider.js` (house DI pattern).** Mirrors `cli-handlers-doctor.js`'s `realDeps()`/injected-deps shape so the CLI is unit-testable without a TTY or a live server. `handleProvider(args)` is exported and imported by `bin/amicus.js` alongside `handleKey`.

13. **`amicus init` extracts postinstall's registration core into `src/utils/claude-register.js`.** Spec §4.8. `scripts/postinstall.js` (`installSkill:87`, `installCouncilSkill:99`, `registerClaudeCode:143`, `registerClaudeDesktop:181`, `migrateLegacyMcp:211`, `addMcpToConfigFile:63`, `MCP_CONFIG:41`) becomes a thin consumer with byte-identical behavior and preserved exports (its test suite keeps passing unmodified). `amicus init` calls the same core with per-step status reporting + `--json` (new thin handler `src/cli-handlers-init.js`).

14. **LM Studio parity is a plan-wide invariant, not an Ollama afterthought (Christian, 2026-07-19).** See Global Constraints — LM Studio is a first-class preset/flavor in EVERY code path (schema, routing, `buildProviderModels`, probe hints, wizard, doctor, docs, errors) and is the PRIMARY real-LLM smoke target in Task 17-testing (Ollama secondary). Wherever the spec's examples lean Ollama-first, this plan gives LM Studio equal or leading treatment.

15. **`config.providers` normalization is forgiving, never fatal (config.js posture).** `loadConfig()` (`config.js:41-55`) already swallows parse errors → `null`. `getLocalProviders()` skips any invalid entry (bad id/scheme/type) with a one-line stderr warning and returns the valid remainder; an absent `providers` key is byte-identical to today. `provider-registry.js` is NEVER imported by `local-providers.js` (leaf-module rule — no require cycle; `getLocalProviders` is lazy-required at its call sites the way `route-launch.js` lazy-requires `config`).

## Shared contracts (referenced by every task)

**Config schema — `config.providers`** (spec §4.1). Top-level key in `~/.config/amicus/config.json` beside `default`/`aliases`/`councils`/`routing`. Map of `id → entry`:

```
ProviderEntry = {
  type: 'openai-compatible',            // required; only value today. Unknown type → entry skipped w/ warn (forward-compat 'aws')
  baseURL: string,                      // required; absolute http:/https: only (any other scheme rejected)
  flavor?: 'ollama'|'lmstudio'|'vllm'|'generic',  // default 'generic'; drives hints + /api/tags fallback + preset URLs; NEVER affects routing
  name?: string,                        // display name (wizard optgroups, models grouping). Default: the id
  apiKeyEnv?: string,                   // env-var NAME for an optional bearer; VALUE lives in .env (0600), never in config.json
  pricing?: { prompt: number, completion: number }  // $/token, non-negative. Default {prompt:0, completion:0} — the $0 tier
}
```

id rules: `^[a-z][a-z0-9_-]{1,31}$`; **reserved** (rejected at add/load): `openrouter`, `google`, `openai`, `anthropic`, `deepseek`.

**`local-providers.js` exports:**
- `getLocalProviders() → Object<id, NormalizedEntry>` — validated + normalized from `loadConfig().providers`; invalid entries skipped w/ stderr warn; absent key → `{}`. `NormalizedEntry` = the `ProviderEntry` with `flavor`/`name`/`pricing` defaulted and `id` stamped on.
- `isLocalProvider(id) → boolean` — `id` is a key in `getLocalProviders()`.
- `deriveKeyEnv(id) → string` — `id.toUpperCase().replace(/[^A-Z0-9]/g,'_') + '_API_KEY'` (`vllm-lab` → `VLLM_LAB_API_KEY`).
- `validateProviderEntry(entry) → {ok:true, normalized}|{ok:false, error}` — id-agnostic field validation (type enum, scheme allowlist, flavor enum, pricing bounds).
- `PRESETS = { ollama:{baseURL:'http://127.0.0.1:11434/v1', flavor:'ollama'}, lmstudio:{baseURL:'http://127.0.0.1:1234/v1', flavor:'lmstudio'}, vllm:{baseURL:'http://127.0.0.1:8000/v1', flavor:'vllm'} }`. **All three presets carry a `baseURL`** (D15/M13 — vLLM's own default serve port is 8000; `--url` overrides any preset). Without it, the documented `--preset vllm` form always exited 1 with "a `--preset` or `--url` is required", a message that misleads because a `--preset` *was* given.
- `RESERVED_IDS = ['openrouter','google','openai','anthropic','deepseek']`.
- `resolveLocalRouteInputs(descriptor, {validateModel, providers}) → Promise<{localProviders?, localLive?}>` — **added by Task 5** (B2/D3). Resolves the optional bearer, stamps `keyPresent`, and runs (or skips) the 2 s probe; returns `{}` when the descriptor's vendor isn't local. `providers` is a parameter so callers/tests control the map.

**`local-probe.js` exports:**
- `probeLocalProvider(entry, {timeoutMs=2000, bearer}) → Promise<{status:'ok'|'unreachable', models:string[]}>` — GET `{baseURL}/models` (i.e. `/v1/models`); on ollama-flavor 404 → GET `{origin}/api/tags`; models normalized to `['<id>/<rawName>', ...]`; unreachable/timeout/parse-fail → `{status:'unreachable', models:[]}`. Never throws. `'skipped'` is set by the CALLER, not here.
- `listLocalModels(entry, {timeoutMs=5000, bearer}) → Promise<Array<CatalogRow>>` — catalog rows `{id:'<id>/<model>', name, contextLength:null, pricing:<entry.pricing>, authoritative:true, local:true}`; `[]` on any failure.

**Router injected inputs (added to the `req` `resolveRoute` receives):**
- `req.localProviders: Object<id, NormalizedEntry & {keyPresent: boolean}>` — the map for THIS request's vendor(s); `keyPresent` pre-resolved by `route-launch.js`.
- `req.localLive: {status:'ok'|'unreachable'|'skipped', models:string[]}` — the probe result (or `{status:'skipped', models:[]}` under `--no-validate-model`).

**`RouteResult` (resolved) for a local vendor:** `{kind:'resolved', model:'<id>/<model>', gateway:'local', executableId:'<id>/<model>', provenance:{source, requested, gatewayMode, resolutionVersion}, notice?}`.

**`RouteResult` (`selection_required`) for a local vendor (D10/M24):** `{kind:'selection_required', requested, suggestions:[{model:'<id>/<model>', gateway:'local', note:'available locally'}, …]}` — the suggestions are the **live probe roster capped at 6** (spec §4.2 point 4), NOT catalog rows. The skip is enforced by `applySuggestions()` in `src/utils/route-suggestions.js` (Task 5 Step 3-pre creates it; Step 3c wires `route-launch.js`'s `selection_required` arm through it).

**`RouteResult` (error) hint field:** any error result MAY carry a `hint: string` composed by the router (Task 4's `localHint()`). `toCliMessage` and `toErrorDocFields` prefer it over `FIX_HINTS[reason]` (Task 3 Step 3c, D1). **`toStructuredError` never carries it** — its 6-key shape is pinned by `tests/route-error.test.js:26-55`.

**New route-error reasons (`route-error.js` maps only):**

- `no_local_key` — "No bearer token is configured for this local provider." / hint "Add one with `amicus key <id> <token>`."

```js
// src/utils/local-providers.js
'use strict';

/**
 * @module local-providers
 * The merge layer beside the static provider-registry (v4.2 §4.1). Reads
 * user-defined OpenAI-compatible providers from config.providers, validates
 * and normalizes them. Forgiving: an invalid entry is skipped with a one-line
 * stderr warning, never fatal (config.js posture). Leaf-ish: only lazy-requires
 * ./config; NEVER requires provider-registry (no cycle, no static-table edits).
 */

const RESERVED_IDS = Object.freeze(['openrouter', 'google', 'openai', 'anthropic', 'deepseek']);
const VALID_FLAVORS = Object.freeze(['ollama', 'lmstudio', 'vllm', 'generic']);
const ID_RE = /^[a-z][a-z0-9_-]{1,31}$/;

/**
 * Preset id → partial entry (baseURL + flavor). ALL THREE carry a baseURL (D15):
 * vLLM's own default `vllm serve` port is 8000, so `--preset vllm` works alone;
 * `--url` overrides any preset for a non-default port or a remote host.
 * 127.0.0.1 never `localhost` (IPv6-first `::1` gotcha, spec §4.1/§4.10).
 */
const PRESETS = Object.freeze({
  ollama: { baseURL: 'http://127.0.0.1:11434/v1', flavor: 'ollama' },
  lmstudio: { baseURL: 'http://127.0.0.1:1234/v1', flavor: 'lmstudio' },
  vllm: { baseURL: 'http://127.0.0.1:8000/v1', flavor: 'vllm' },
});

/** `vllm-lab` → `VLLM_LAB_API_KEY`. @param {string} id @returns {string} */
function deriveKeyEnv(id) {
  return `${String(id).toUpperCase().replace(/[^A-Z0-9]/g, '_')}_API_KEY`;
}

/** Absolute http:/https: only. @param {string} u @returns {boolean} */
function isAllowedUrl(u) {
  try {
    const parsed = new URL(u);
    return parsed.protocol === 'http:' || parsed.protocol === 'https:';
  } catch { return false; }
}

/**
 * Validate + normalize a provider entry (id-agnostic — id is checked at the map level).
 * @param {object} entry @returns {{ok:true, normalized:object}|{ok:false, error:string}}
 */
function validateProviderEntry(entry) {
  if (!entry || typeof entry !== 'object') { return { ok: false, error: 'entry must be an object' }; }
  if (entry.type !== 'openai-compatible') { return { ok: false, error: `unsupported type '${entry.type}'` }; }
  if (typeof entry.baseURL !== 'string' || !isAllowedUrl(entry.baseURL)) {
    return { ok: false, error: `baseURL must be an absolute http:/https: URL (got '${entry.baseURL}')` };
  }
  const flavor = entry.flavor === undefined ? 'generic' : entry.flavor;
  if (!VALID_FLAVORS.includes(flavor)) { return { ok: false, error: `invalid flavor '${entry.flavor}'` }; }
  let pricing = { prompt: 0, completion: 0 };
  if (entry.pricing !== undefined) {
    const p = entry.pricing;
    const prompt = Number(p && p.prompt);
    const completion = Number(p && p.completion);
    if (!Number.isFinite(prompt) || !Number.isFinite(completion) || prompt < 0 || completion < 0) {
      return { ok: false, error: 'pricing.prompt/completion must be non-negative numbers' };
    }
    pricing = { prompt, completion };
  }
  const normalized = {
    type: 'openai-compatible',
    baseURL: entry.baseURL,
    flavor,
    name: typeof entry.name === 'string' && entry.name ? entry.name : undefined,
    apiKeyEnv: typeof entry.apiKeyEnv === 'string' && entry.apiKeyEnv ? entry.apiKeyEnv : undefined,
    pricing,
  };
  return { ok: true, normalized };
}

/**
 * Validated, normalized local-provider map from config.providers.
 * Invalid/reserved/malformed-id entries are skipped with a stderr warning.
 * @returns {Object<string, object>} id → normalized entry (id stamped on; name defaulted to id)
 */
function getLocalProviders() {
  let config;
  try { config = require('./config').loadConfig(); } catch { config = null; }
  const raw = (config && config.providers && typeof config.providers === 'object') ? config.providers : {};
  const out = {};
  for (const [id, entry] of Object.entries(raw)) {
    if (!ID_RE.test(id) || RESERVED_IDS.includes(id)) {
      process.stderr.write(`Notice: skipping invalid provider id '${id}' in config.providers.\n`);
      continue;
    }
    const v = validateProviderEntry(entry);
    if (!v.ok) {
      process.stderr.write(`Notice: skipping provider '${id}' — ${v.error}.\n`);
      continue;
    }
    out[id] = { ...v.normalized, id, name: v.normalized.name || id };
  }
  return out;
}

/** @param {string} id @returns {boolean} */
function isLocalProvider(id) {
  return !!id && Object.prototype.hasOwnProperty.call(getLocalProviders(), id);
}

module.exports = {
  getLocalProviders, isLocalProvider, deriveKeyEnv, validateProviderEntry,
  PRESETS, RESERVED_IDS, VALID_FLAVORS, ID_RE,
};
```

```js
// src/utils/local-probe.js
'use strict';

/**
 * @module local-probe
 * Scheme-aware (http/https) bounded GET for local / OpenAI-compatible servers
 * (v4.2 §3 http-fix, §4.2 route-time probe, §4.4 catalog rows). Fixes the
 * model-fetcher https-only silent-[] bug for local http endpoints. No redirects
 * followed; bearer attached only to the configured origin; Authorization never
 * logged. Never throws — every failure resolves to unreachable / [].
 */

const http = require('http');
const https = require('https');

/** GET JSON with a hard timeout; no redirect follow. Resolves {status, body} or {status:0}. */
function getJson(url, { timeoutMs, bearer }) {
  return new Promise((resolve) => {
    let parsed;
    try { parsed = new URL(url); } catch { resolve({ status: 0 }); return; }
    const mod = parsed.protocol === 'https:' ? https : http;
    const headers = bearer ? { Authorization: `Bearer ${bearer}` } : {};
    let body = '';
    const req = mod.get(url, { headers }, (res) => {
      const status = res.statusCode || 0;
      // Non-200 (incl. 3xx redirects — NOT followed) → drain + report status, no body parse.
      if (status !== 200) { res.on('data', () => {}); res.on('end', () => resolve({ status })); return; }
      res.on('data', (c) => { body += c; });
      res.on('end', () => { try { resolve({ status, body: JSON.parse(body) }); } catch { resolve({ status: 0 }); } });
    });
    const timer = setTimeout(() => { req.destroy(); resolve({ status: 0 }); }, timeoutMs);
    req.on('error', () => { clearTimeout(timer); resolve({ status: 0 }); });
    req.on('close', () => clearTimeout(timer));
  });
}

/** Trim a trailing `/v1` (or `/`) off the baseURL to get the server origin for /api/tags. */
function originOf(baseURL) {
  try { const u = new URL(baseURL); return `${u.protocol}//${u.host}`; } catch { return baseURL; }
}

/** OpenAI /v1/models body → ['<id>/<model>', ...]. */
function idsFromV1(id, body) {
  const data = (body && Array.isArray(body.data)) ? body.data : [];
  return data.map((m) => m && m.id).filter(Boolean).map((name) => `${id}/${name}`);
}

/** Ollama /api/tags body → ['<id>/<model>', ...]. */
function idsFromTags(id, body) {
  const models = (body && Array.isArray(body.models)) ? body.models : [];
  return models.map((m) => m && m.name).filter(Boolean).map((name) => `${id}/${name}`);
}

/**
 * Route-time reachability probe (spec §4.2). Never throws.
 * @param {{id:string, baseURL:string, flavor?:string}} entry
 * @param {{timeoutMs?:number, bearer?:string}} [opts]
 * @returns {Promise<{status:'ok'|'unreachable', models:string[]}>}
 */
async function probeLocalProvider(entry, opts = {}) {
  const timeoutMs = opts.timeoutMs || 2000;
  const bearer = opts.bearer;
  const primary = await getJson(`${entry.baseURL.replace(/\/$/, '')}/models`, { timeoutMs, bearer });
  if (primary.status === 200) { return { status: 'ok', models: idsFromV1(entry.id, primary.body) }; }
  // Ollama-flavor fallback: older servers answer /api/tags, not /v1/models.
  if (entry.flavor === 'ollama' && primary.status === 404) {
    const tags = await getJson(`${originOf(entry.baseURL)}/api/tags`, { timeoutMs, bearer });
    if (tags.status === 200) { return { status: 'ok', models: idsFromTags(entry.id, tags.body) }; }
  }
  return { status: 'unreachable', models: [] };
}

/**
 * Catalog rows (spec §4.4). Never throws; [] on any failure.
 * @param {{id:string, baseURL:string, flavor?:string, pricing?:object}} entry
 * @param {{timeoutMs?:number, bearer?:string}} [opts]
 * @returns {Promise<Array<object>>}
 */
async function listLocalModels(entry, opts = {}) {
  const timeoutMs = opts.timeoutMs || 5000;
  const probe = await probeLocalProvider(entry, { timeoutMs, bearer: opts.bearer });
  if (probe.status !== 'ok') { return []; }
  const pricing = entry.pricing || { prompt: 0, completion: 0 };
  return probe.models.map((id) => ({
    id, name: id.slice(entry.id.length + 1), contextLength: null, pricing,
    authoritative: true, local: true,
  }));
}

module.exports = { probeLocalProvider, listLocalModels };
```

```js
  const f = entry && entry.flavor;
  if (kind === 'unreachable') {
    if (f === 'ollama') { return 'Is Ollama running? `ollama serve`'; }
    if (f === 'lmstudio') { return 'Start the LM Studio server (Developer → Start Server).'; }

  // model_not_found
  return f === 'ollama' ? `Model not pulled — \`ollama pull ${(entry && entry.model) || '<model>'}\`.`
    : `Load the model in ${f === 'lmstudio' ? 'LM Studio' : 'the server'} first.`;

 * Local-provider branch (v4.2 §4.2). The vendor is a configured local provider
 * (key in req.localProviders). Returns a RouteResult; never consults the cached
 * catalog (route-time truth is the injected live probe).

function resolveLocal(d, req) {
  const entry = req.localProviders[d.vendor];
  const executableId = executableFor('direct', d.vendor, d.model); // `<id>/<model>`, no openrouter/ prefix
  // 1. OpenRouter is never a local route.
  if (d.isExplicitOpenRouter || req.gatewayMode === 'openrouter') {
    return routeError({ requested: d.raw, reason: 'no_openrouter_route', preferredGateway: 'direct', suggestions: [] });
  }
  // 2. Declared-but-missing bearer.
  if (entry.apiKeyEnv && !entry.keyPresent) {
    return routeError({ requested: d.raw, reason: 'no_local_key', preferredGateway: 'direct', suggestions: [] });
  }
  const live = req.localLive || { status: 'skipped', models: [] };
  // 3. Unreachable (never reached under --no-validate-model — status is 'skipped' then).
  if (live.status === 'unreachable') {
    const e = routeError({ requested: d.raw, reason: 'local_endpoint_unreachable', preferredGateway: 'direct', suggestions: [] });
    e.hint = localHint(entry, 'unreachable');
    return e;
  }
  // 4. Reachable but the model is absent from the live roster.
  if (live.status === 'ok' && !live.models.includes(executableId)) {
    if (req.allowSelection) {
      const suggestions = live.models.slice(0, 6).map((id) => ({ model: id, gateway: 'local', note: 'available locally' }));
      return selectionRequired({ requested: d.raw, suggestions });

    const e = routeError({ requested: d.raw, reason: 'model_not_found', preferredGateway: 'direct', suggestions: [] });
```

```js
/**
 * v4.2: assemble the router's local inputs for one descriptor.
 * Lives here (not in route-launch.js) so route-launch stays under the 300-line gate.
 * `providers` is a PARAMETER, not a bare same-module `getLocalProviders()` call, so
 * callers/tests control the map (cf. B3: bare identifiers are unmockable via the exports object).
 * @returns {Promise<{localProviders?: Object, localLive?: Object}>} — `{}` for a non-local vendor.
 */
async function resolveLocalRouteInputs(descriptor, { validateModel, providers } = {}) {
  const all = providers || getLocalProviders();
  const vendor = descriptor && descriptor.vendor;
  const entry = vendor && all && all[vendor];
  if (!entry) { return {}; }
  let bearer;
  if (entry.apiKeyEnv) {
    const { readApiKeyValues } = require('./api-key-store');
    bearer = process.env[entry.apiKeyEnv] ||
      (readApiKeyValues && readApiKeyValues()[vendor]) || undefined;

    ? { status: 'skipped', models: [] }
    : await require('./local-probe').probeLocalProvider(entry, { timeoutMs: 2000, bearer });

}
```

```js
  if (row && row.pricing) {
    const prompt = Number(row.pricing.prompt);
    const completion = Number(row.pricing.completion);
    if (Number.isFinite(prompt) && Number.isFinite(completion) && prompt >= 0 && completion >= 0) {
      return { prompt, completion };
    }
```

```js
// src/cli-handlers-provider.js
'use strict';

/**
 * `amicus provider add|list|test|remove` (v4.2 §4.6). Writes config.providers +
 * bearer secrets; probes; runs the shared per-provider default picker. DI-injected
 * (print/emitJson/probe) so it is unit-testable without a TTY or a live server.
 */

const { PRESETS, RESERVED_IDS, ID_RE, validateProviderEntry, deriveKeyEnv, getLocalProviders } = require('./utils/local-providers');

function realDeps() {
  return {
    loadConfig: () => require('./utils/config').loadConfig(),
    saveConfig: (c) => require('./utils/config').saveConfig(c),
    saveApiKey: (env, val) => require('./utils/api-key-store').saveRawEnv(env, val),
    probe: (e, o) => require('./utils/local-probe').probeLocalProvider(e, o),
    readCache: () => require('./utils/model-catalog').readCache(),
    runDefault: (id, o) => require('./utils/provider-default-prompt').runProviderDefaultFlow(id, o),
    print: (l) => process.stdout.write(`${l}\n`),
    emitJson: (o) => process.stdout.write(`${JSON.stringify(o, null, 2)}\n`),
    warn: (l) => process.stderr.write(`${l}\n`),
  };
}

/** Build the entry from --preset or --url (+ optional bearer/pricing). */
function entryFromArgs(id, args) {
  const preset = args.preset ? PRESETS[args.preset] : null;
  const baseURL = args.url || (preset && preset.baseURL);
  const flavor = (preset && preset.flavor) || 'generic';
  // D15/M13: every PRESETS entry carries a baseURL, so this now fires only when NEITHER
  // flag was given, or when --preset named something unknown. Distinguish the two — the
  // old single message misled anyone who HAD passed --preset.
  if (!baseURL) {
    return { error: args.preset && !preset
      ? `unknown --preset '${args.preset}' (expected: ${Object.keys(PRESETS).join('|')})`
      : 'a --preset or --url is required' };
  }
  const entry = { type: 'openai-compatible', baseURL, flavor };
  if (args['pricing-in'] !== undefined || args['pricing-out'] !== undefined) {
    entry.pricing = { prompt: Number(args['pricing-in']) || 0, completion: Number(args['pricing-out']) || 0 };
  }
  if (args['bearer-env']) { entry.apiKeyEnv = args['bearer-env']; }
  else if (args.bearer) { entry.apiKeyEnv = deriveKeyEnv(id); }
  return { entry, bearerValue: args.bearer };
}

async function doAdd(id, args, d) {
  if (!ID_RE.test(id) || RESERVED_IDS.includes(id)) {
    d.warn(`Invalid or reserved provider id: '${id}'.`); return 1;
  }
  const built = entryFromArgs(id, args);
  if (built.error) { d.warn(built.error); return 1; }
  const v = validateProviderEntry(built.entry);
  if (!v.ok) { d.warn(v.error); return 1; }
  // Plaintext-credential warning: non-loopback http + bearer.
  if (built.bearerValue && /^http:\/\//.test(built.entry.baseURL) && !/\/\/(127\.0\.0\.1|localhost)/.test(built.entry.baseURL)) {
    d.warn('Warning: a bearer over plain http:// on a non-loopback host sends credentials in cleartext.');
  }
  // Shadow warning: catalog contains openrouter/<id>/ rows (decision 5).
  const cache = d.readCache();
  if (cache && Array.isArray(cache.models) && cache.models.some((m) => m && typeof m.id === 'string' && m.id.startsWith(`openrouter/${id}/`))) {
    d.warn(`Note: '${id}' shadows an OpenRouter vendor namespace for bare model ids. Use openrouter/${id}/... to reach OpenRouter.`);
  }
  // Persist: bearer to .env, entry to config.
  // M12: saveRawEnv VALIDATES envVar against /^[A-Z][A-Z0-9_]*$/ and returns
  // {success:false, error} WITHOUT throwing — precisely so callers can detect a failed
  // write. It is the ONLY validation of a user-supplied --bearer-env (entryFromArgs
  // never checks the format, and validateProviderEntry is documented as covering only
  // type/scheme/flavor/pricing). Dropping the return value persists an entry carrying a
  // rejected apiKeyEnv and reports success. The direct-vendor path already does this
  // correctly at src/cli-handlers.js:156-160 — mirror it, and bail BEFORE saving config.
  if (built.entry.apiKeyEnv && built.bearerValue) {
    const saved = d.saveApiKey(built.entry.apiKeyEnv, built.bearerValue);
    if (saved && saved.success === false) { d.warn(saved.error); return 1; }
  }
  const config = d.loadConfig() || {};
  config.providers = config.providers || {};
  config.providers[id] = v.normalized;
  // B7/D4: do NOT seed config.default here. A bare id is unresolvable by resolveModel()
  // unless config.aliases[id] exists, and only applyProviderDefault writes that pair
  // (alias first, then default). Seeding it before the probe permanently breaks every
  // later keyless `amicus start`/`fanout`/`continue` for the air-gapped first-run order.
  // applyProviderDefault (via d.runDefault below) is the SOLE writer of config.default.
  d.saveConfig(config);
  // Probe (best-effort — a failure never blocks the save; air-gap rule).
  const bearer = built.bearerValue;
  const probe = await d.probe({ ...v.normalized, id }, { timeoutMs: 2000, bearer });
  if (probe.status === 'ok') {
    d.print(`Added '${id}' — ${probe.models.length} model(s) found.`);
    try {
      const catalog = probe.models.map((mid) => ({ id: mid, pricing: v.normalized.pricing, local: true }));
      const { summaryLine } = await d.runDefault(id, { interactive: false, catalog });
      if (summaryLine) { d.print(summaryLine); }
    } catch { /* picker is best-effort */ }
  } else {
    d.warn(`Added '${id}' but the endpoint was unreachable — check the server and run \`amicus provider test ${id}\`.`);
  }
  if (args.json) { d.emitJson({ ok: true, id, reachable: probe.status === 'ok', models: probe.models }); }
  return 0;
}

async function doTest(id, args, d) {
  const entry = getLocalProviders()[id];
  if (!entry) { d.warn(`No local provider '${id}'.`); return 1; }
  const bearer = entry.apiKeyEnv ? process.env[entry.apiKeyEnv] : undefined;
  const probe = await d.probe(entry, { timeoutMs: 2000, bearer });
  if (args.json) { d.emitJson({ ok: probe.status === 'ok', id, reachable: probe.status === 'ok', models: probe.models, bearer: !!bearer }); }
  else { d.print(probe.status === 'ok' ? `${id}: ${probe.models.length} model(s) @ ${entry.baseURL}` : `${id}: unreachable @ ${entry.baseURL}`); }
  return probe.status === 'ok' ? 0 : 1;
}

function doList(args, d) {
  const map = getLocalProviders();
  const providers = Object.values(map).map((e) => ({ id: e.id, baseURL: e.baseURL, flavor: e.flavor, bearer: !!e.apiKeyEnv }));
  if (args.json) { d.emitJson({ providers }); }
  else if (providers.length === 0) { d.print('No local providers configured. Add one: amicus provider add ollama --preset ollama'); }
  else { for (const p of providers) { d.print(`${p.id}  ${p.baseURL}  [${p.flavor}]${p.bearer ? '  (bearer)' : ''}`); } }
  return 0;
}

function doRemove(id, args, d) {
  const config = d.loadConfig() || {};
  if (!config.providers || !config.providers[id]) { d.warn(`No local provider '${id}'.`); return 1; }
  const entry = config.providers[id];
  delete config.providers[id];
  if (config.default === id) { delete config.default; }
  if (config.aliases && config.aliases[id]) { delete config.aliases[id]; }
  d.saveConfig(config);
  if (entry.apiKeyEnv) { d.warn(`Note: the bearer line ${entry.apiKeyEnv} in .env was left in place — remove it with \`amicus key ${id} --remove\`.`); }
  if (args.json) { d.emitJson({ ok: true, removed: id }); } else { d.print(`Removed '${id}'.`); }
  return 0;
}

/** @param {object} args parsed CLI args (args._ = ['provider', <sub>, <id?>]) @param {object} [deps] */
async function handleProvider(args, deps = {}) {
  const d = { ...realDeps(), ...deps };
  const sub = args._[1];
  const id = args._[2];
  if (sub === 'add') { return doAdd(id, args, d); }
  if (sub === 'test') { return doTest(id, args, d); }
  if (sub === 'list') { return doList(args, d); }
  if (sub === 'remove') { return doRemove(id, args, d); }
  d.warn('Usage: amicus provider add|list|test|remove');
  return 1;
}

module.exports = { handleProvider };
```

```js
// src/utils/env-raw-store.js
'use strict';

/**
 * Arbitrary-env-var writes to the amicus .env (local-provider bearers, v4.2 §4.6).
 * Split out of api-key-store.js to keep that file under the 300-line gate (B2/D3).
 * `getEnvPath` is required LAZILY inside each function so api-key-store.js can
 * re-export from here without a load-time require cycle.
 */

const fs = require('fs');
const path = require('path');

/**
 * Write an arbitrary env-var line to the amicus .env (local-provider bearers).
 * Parallel to saveApiKey but keyed on the env-var NAME directly (no PROVIDER_ENV_MAP).
 * Preserves comments/other lines, dedups the target line, writes 0600, and mirrors
 * the value into process.env for immediate availability.
 * @param {string} envVar e.g. 'LAB_API_KEY'
 * @param {string} value bearer token
 * @returns {{success: boolean, error?: string}}
 */
function saveRawEnv(envVar, value) {
  if (typeof envVar !== 'string' || !/^[A-Z][A-Z0-9_]*$/.test(envVar)) {
    return { success: false, error: `Invalid env var name: ${envVar}` };
  }
  const { getEnvPath } = require('./api-key-store'); // lazy: avoids a load-time cycle
  const envPath = getEnvPath();
  const envDir = path.dirname(envPath);
  fs.mkdirSync(envDir, { recursive: true });

  let lines = [];
  try {
    if (fs.existsSync(envPath)) {
      lines = fs.readFileSync(envPath, 'utf-8').split('\n');
    }
  } catch (_err) {
    // Start fresh
  }

  let found = false;
  for (let i = 0; i < lines.length; i++) {
    if (lines[i].trim().startsWith(envVar + '=')) {
      lines[i] = `${envVar}=${value}`;
      found = true;
      break;
    }
  }
  if (!found) {
    while (lines.length > 0 && lines[lines.length - 1].trim() === '') {
      lines.pop();
    }
    lines.push(`${envVar}=${value}`);
  }

  fs.writeFileSync(envPath, lines.join('\n') + '\n', { mode: 0o600 });
  process.env[envVar] = value;
  return { success: true };
}

/**
 * Remove an arbitrary env-var line from the amicus .env (local-provider bearers).
 * Parallel to removeApiKey but keyed on the env-var NAME directly and WITHOUT the
 * auth.json reconciliation (local providers have no auth.json entry).
 * @param {string} envVar e.g. 'LAB_API_KEY'
 * @returns {{success: boolean}}
 */
function removeRawEnv(envVar) {
  const { getEnvPath } = require('./api-key-store'); // lazy: avoids a load-time cycle
  const envPath = getEnvPath();
  try {
    if (fs.existsSync(envPath)) {
      const lines = fs.readFileSync(envPath, 'utf-8').split('\n')
        .filter((line) => !line.trim().startsWith(envVar + '='));
      while (lines.length > 0 && lines[lines.length - 1].trim() === '') {
        lines.pop();
      }
      const output = lines.length > 0 ? lines.join('\n') + '\n' : '';
      fs.writeFileSync(envPath, output, { mode: 0o600 });
    }
  } catch (_err) {
    // Best-effort
  }
  delete process.env[envVar];
  return { success: true };
}

module.exports = { saveRawEnv, removeRawEnv };
```

```js
// src/utils/doctor-summary.js
'use strict';

/**
 * Compact doctor summary (v4.2 §4.7 C8). All-ok → one line; otherwise the
 * non-ok lines + counts + a pointer to the full command. Shared by the setup
 * wizard finale and `amicus init`.
 * @param {Array<{status:string,name?:string,message?:string}>} checks
 * @returns {string}
 */
function summarizeDoctor(checks) {
  const list = Array.isArray(checks) ? checks : [];
  const nonOk = list.filter((c) => c && c.status !== 'ok');
  if (nonOk.length === 0) { return `doctor: all ${list.length} checks pass`; }
  const errors = nonOk.filter((c) => c.status === 'error').length;
  const warns = nonOk.filter((c) => c.status === 'warn').length;
  const lines = nonOk.map((c) => `  ${c.status === 'error' ? '✗' : '⚠'} ${c.name || c.id}: ${c.message || ''}`.trimEnd());
  lines.push(`${errors} error(s), ${warns} warning(s) — run \`amicus doctor\` for details`);
  return lines.join('\n');
}

module.exports = { summarizeDoctor };
```

```js
// src/cli-handlers-init.js
'use strict';

/**
 * `amicus init [--claude] [--desktop] [--json]` (v4.2 §4.8, C2). Runs the same
 * registration core postinstall does, on demand, with per-step status + a
 * compact doctor summary. Works for plugin-channel/--ignore-scripts installs and
 * repairs deleted ~/.claude state. Never does keys/model setup or engine/electron
 * provisioning (that is `amicus setup` / `amicus doctor --fix`).
 */

function realDeps() {
  return {
    reg: require('./utils/claude-register'),
    runDoctorChecks: (o) => require('./cli-handlers-doctor').runDoctorChecks(o),
    summarizeDoctor: (c) => require('./utils/doctor-summary').summarizeDoctor(c),
    print: (l) => process.stdout.write(`${l}\n`),
    emitJson: (o) => process.stdout.write(`${JSON.stringify(o, null, 2)}\n`),
  };
}

async function handleInit(args, deps = {}) {
  const d = { ...realDeps(), ...deps };
  const both = !args.claude && !args.desktop;
  const steps = {};
  try {
    d.reg.installSkill();
    d.reg.installCouncilSkill();
    steps.skills = 'done';
    // M18: see the note below — these two must actually RETURN a status, or `|| 'done'`
    // fires on every real invocation and the per-step report is a constant.
    if (both || args.claude) { steps.claudeCode = d.reg.registerClaudeCode() || 'done'; }
    if (both || args.desktop) { steps.claudeDesktop = d.reg.registerClaudeDesktop() || 'done'; }
    d.reg.migrateLegacyMcp();
    steps.legacyMigration = 'done';
  } catch (e) {
    if (args.json) { d.emitJson({ ok: false, error: e.message, steps }); } else { d.print(`init failed: ${e.message}`); }
    return 1;
  }
  let summary = '';
  try { summary = d.summarizeDoctor(await d.runDoctorChecks()); } catch { summary = ''; }
  if (args.json) { d.emitJson({ ok: true, steps }); }
  else {
    for (const [k, v] of Object.entries(steps)) { d.print(`  ${k}: ${v}`); }
    if (summary) { d.print(summary); }
  }
  return 0;
}

module.exports = { handleInit };
```
