## 2. The ruling this plan implements (owner, 2026-08-19)

R2 asks: *what happens to a record whose seat cannot be identified?* Its answer is **hybrid** — mint
a distinguisher where the producer has one; **where it genuinely has nothing, mark explicitly,
attribute nothing, announce on a channel.**

For SI-22.1 / SI-22.2 the consumer genuinely has nothing: a **seatless `deepseek` vote cannot be
told apart from the raiser's own**. So:

- **`basis` does not move.** The drop stays. This is forced, not preferred: §0.6 measures that
  counting the vote reproduces **NAIVE's** outcome on both fixtures (`a:1` → Confirmed), which is
  precisely the *"silently promotes a Singleton to Confirmed on the raiser's own vote"* re-arm of
  **#137** that trap #1 and SI-04 name. Counting it would also leave the naive form **unpinned in
  the very release that fixes the bug it re-arms**.
- **The drop is marked.** An additive per-finding count, emitted **only when non-zero**, so every
  run that does not orphan exactly one side of a twin pair is byte-for-byte unchanged (§0.6).
- **T2.4 renders it** beside SI-22.5's unattributed column (R3). This PR produces the data only.

**Marker contract (both documents, same name and same meaning):**

- Field: **`unattributedPeerDrops: <number>`** — count of adjudications excluded because the alias
  fallback ran with **exactly one** side carrying a seat id.
- Emitted only when `> 0`. Absent otherwise. Additive; no existing field changes.
- `tally.js` → on each `outFindings[]` row, beside `sameModelCorroboration` (the existing precedent
  for an emit-when-true additive stamp).
- `debate.js` → on each `byRaiser[key][]` row, beside `peerVerdicts`, so the defense brief and the
  tally the chair reads **cannot disagree**.

⚠️ The predicate is *not* "the alias branch ran". On a unique-alias bench neither side is seated,
the alias compare excludes the raiser's own vote, and that exclusion is **correct and
unambiguous** — it must not be marked. The predicate requires **exactly one** side seated:

```js
!(v.seat && f.raiserSeat) && (!!v.seat !== !!f.raiserSeat) && v.judge === f.raiser
```

Measured against all four shapes in §0.6: fires 1/1/0/0. Assert **every conjunct in the expression**
— do not infer one from a branch (plan-failure #8, the asserted property).
