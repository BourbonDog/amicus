the same `formatDegrade` voice; and Stage-2 judge legs finally get `runStats` rows (**#83**).

## Task 4: Derive `seatLoss` from the records — closes #84

**Files:**
- Modify: `src/council/verdict.js` (new `deriveSeatLoss`; `summarizeSeatLoss` UNTOUCHED),

**Interfaces:**
- Consumes: Task 2's `data` shapes; Task 3's `degrades` param.
- Produces: `deriveSeatLoss({runId, critic, degrades}) → same shape as summarizeSeatLoss`.

**Design (spec D3), and why composition:** the v4.5.2 unit tests call `summarizeSeatLoss`
directly with `{runId, critic, deadWaves}` and MUST pass unedited — so that function does not
change. `deriveSeatLoss` rebuilds its wave input from `dead-wave` records' `data` and extends the
result with what `summarizeSeatLoss` could never see: `dead-leg` records. Production
(`writeVerdictFiles`) prefers the derivation whenever `degrades` was provided, so the runtime path
has ONE source of truth (the sink) and `verdict.seatLoss` can no longer disagree with
`verdict.degrades`. The `deadWaves` param remains as the no-degrades fallback for direct callers.

#84's two halves, and where each closes: a dead **bench leg** now reaches `deadBenchSeats` (with a
critic requested) and is always named in `degrades[]` (without one); a dead **critic leg** — a
solo wave that started but whose one leg died, invisible to `deadWaves` — now flips
`criticSeated`.

 * @returns {?object} the summarizeSeatLoss shape, or null when no critic was requested
 */
function deriveSeatLoss({ runId, critic, degrades = [] } = {}) {
  if (!critic) { return null; }
  const real = degrades.filter(d => d.kind !== 'heal' && d.data);
  const waves = real.filter(d => d.channel === 'dead-wave')
    .map(d => ({ waveId: d.data.waveId, models: d.data.models || [], reason: d.data.reason }));
  const base = summarizeSeatLoss({ runId, critic, deadWaves: waves });
  const legs = real.filter(d => d.channel === 'dead-leg');
  const criticLeg = legs.find(l => l.data.seat === critic) || null;
  return {
    ...base,
    criticSeated: base.criticSeated && !criticLeg,
    reason: base.reason || (criticLeg
      ? (criticLeg.data.reason || `the critic leg ended '${criticLeg.data.status}' with no usable output`)
      : null),
    deadBenchSeats: [...base.deadBenchSeats,
      ...legs.filter(l => l.data.seat !== critic).map(l => l.data.seat)],
  };
}
