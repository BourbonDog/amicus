> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** spec §6 (R2, D5) — an opt-in `--live` tier for `models --check`: one ordinary engine
leg per STORED alias, classified **served / accepted-but-silent / error**, the silent class
detected by PR2's no-output backstop with a 30 s override. Presence in the catalog is not proof
of service; this is the check that would have caught the v4.6.1 `gemini` incident outright.

**Architecture:** thread `noOutputBackstopMs` through `runFanout` → `runLeg` → `runHeadless`
(adding the recorded numeric-coercion guard at the `runHeadless` seam); a new
`src/sidecar/models-probe.js` builds ONE quiet fanout wave over the stored-alias targets and
classifies its legs; `runCheck` in `src/sidecar/models.js` gains the `--live` branch (spend
gate = the flag), human table + additive `probe` field on the audit doc.

**Tech Stack:** Node 18 CommonJS, jest, house patterns. Base: `main@7cbe293` (PR2 merged — the
backstop module and `options.noOutputBackstopMs` seam exist).

### Task 2: `models-probe` module

**Files:**
- Create: `src/sidecar/models-probe.js`
- Test: `tests/sidecar/models-probe.test.js`

**Interfaces:**
- Consumes: `runFanout` (injected via `deps` for tests), `collectAliasSources`.
- Produces:

```js
const PROBE_WINDOW_MS = 30000;
const PROBE_PROMPT = 'Reply with exactly: OK';

/**
 * Probe every STORED alias with one ordinary engine leg (real session dirs,
 * real spend rows — D5) on one quiet fanout wave. Returns per-alias outcomes;
 * never called without --live (the spend gate lives in the CLI layer).
 * @param {{project?:string}} opts
 * @param {{runFanout?:Function, collectAliasSources?:Function}} [deps]
 * @returns {Promise<{results:Array<{alias:string,target:string,outcome:'served'|'accepted-but-silent'|'error',detail:string|null,cost:number|null}>, waveId:string|null}>}
 */
async function probeStoredAliases(opts = {}, deps = {}) { ... }
```

Implementation contract: collect `user-config` rows; empty → `{results: [], waveId: null}` (the
CLI prints "no stored aliases to probe"). One `runFanout` call: `models` = the stored targets,
`prompt: PROBE_PROMPT`, `quiet: true`, `noOutputBackstopMs: PROBE_WINDOW_MS`,
`timeout: 2` (minutes — the overall ceiling behind the backstop), `project: opts.project`.
Classify each leg per the Global Constraints contract, mapping legs back to aliases by array
order (`deriveLegIds` is positional — pin that assumption with a test against `runFanout`'s
mocked leg order). `detail` = the leg error string (null for served); `cost` = the leg's cost
where the wave doc carries one, else null.
